# Customer_Shopping_Behavior_Analysis – Data Analytics Project
 An end-to-end data analytics project focused on analyzing customer shopping behavior to uncover purchasing patterns, customer preferences, and business insights. The project covers the complete data analytics workflow, from data loading and cleaning to SQL analysis and interactive Power BI visualization.

Tools & Technologies

- Python: Data loading, exploration, and cleaning.

- Pandas: Data manipulation and analysis.

* MySQL: SQL queries and business analysis.

+ Power BI: Interactive dashboard development.

+ Jupyter Notebook: Python-based analysis.

Project Workflow

1. Data Loading: Imported the customer shopping dataset into Python.

2. Exploratory Data Analysis (EDA): Explored the dataset to understand its structure, distributions, and patterns.

3. Data Cleaning: Handled missing values, duplicates, and data inconsistencies.

4. SQL Analysis: Loaded the cleaned dataset into MySQL and performed SQL queries to answer business questions.

5. Dashboard Development: Connected the analysis to Power BI and developed an interactive dashboard.

6. Insights & Reporting: Identified key trends and presented findings through visualizations.
